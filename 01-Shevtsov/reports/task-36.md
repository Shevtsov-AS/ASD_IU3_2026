# Задача № 36. Префиксные суммы массива

## Алгоритм решения

Последовательно обрабатываем элементы массива. Для каждого элемента прибавляем его значение к накопленной сумме и записываем полученную сумму в соответствующую позицию результирующего массива.

## Сложность алгоритма

- **Временная сложность:** O(n), где n — количество элементов исходного массива.
- **Дополнительная пространственная сложность:** O(n), поскольку создаётся результирующий массив префиксных сумм.

## Результаты ручного тестирования

| Входные данные | Ожидаемый результат |
|---|---|
| `4 2 3 -1 4` | `2 5 4 8` |
| `0` | пустая строка |
| `3 -3 -4 5` | `-3 -7 -2` |
