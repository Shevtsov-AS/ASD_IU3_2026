# Задача 43. Перемещение нулей в конец

## Условие

Дан массив целых чисел. Необходимо переместить все нули в конец массива, сохранив исходный порядок ненулевых элементов. Массив должен быть изменён на месте.

## Формат ввода

- Первая строка: целое число `n` — количество элементов массива.
- Вторая строка: `n` целых чисел — элементы массива.

## Формат вывода

Элементы изменённого массива через пробел.

## Алгоритм

1. Создаётся индекс `index`, указывающий на позицию для следующего ненулевого элемента.
2. Массив обходится слева направо. Каждый ненулевой элемент записывается в позицию `index`, после чего индекс увеличивается.
3. Все позиции от `index` до конца массива заполняются нулями.
4. Изменённый массив выводится через пробел.

Алгоритм изменяет исходный массив и не создаёт дополнительный массив.

## Сложность

Временная сложность: O(n), поскольку элементы массива обрабатываются линейно.

Дополнительная пространственная сложность: O(1), поскольку используются только несколько переменных.

## Ручные тесты

| Входные данные | Ожидаемый результат |
|---|---|
| `5 0 1 0 3 12` | `1 3 12 0 0` |
| `3 1 2 3` | `1 2 3` |
| `3 0 0 0` | `0 0 0` |
