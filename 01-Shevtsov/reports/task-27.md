# Задача № 27. Сумма квадратов элементов массива

## Алгоритм решения

Последовательно просматриваем элементы массива, возводим каждый элемент в квадрат и прибавляем полученное значение к общей сумме. Для хранения результата используется тип `long`.

Если массив пуст, результат равен нулю.

## Сложность алгоритма

- **Временная сложность:** O(n), где n — количество элементов массива.
- **Дополнительная пространственная сложность:** O(1), не считая памяти, занятой входным массивом.

## Результаты ручного тестирования

| Входные данные | Ожидаемый результат |
|---|---:|
| `3 3 4 1` | `26` |
| `3 -1 2 -3` | `14` |
| `0` | `0` |
