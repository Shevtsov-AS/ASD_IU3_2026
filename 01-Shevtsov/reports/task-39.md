# Задача № 39. Циклический сдвиг массива вправо

## Формат входных данных

В первой строке вводится целое число `n` — количество элементов массива. Во второй строке вводятся `n` целых чисел, разделённых пробелами. В последней строке вводится целое число `k` — величина сдвига вправо.

## Формат выходных данных

Программа выводит элементы массива после циклического сдвига вправо на `k` позиций.

## Алгоритм решения

Сначала нормализуем величину сдвига по длине массива. Затем разворачиваем весь массив, после чего отдельно разворачиваем первые `k` элементов и оставшуюся часть. Это обеспечивает циклический сдвиг без создания дополнительного массива.

Если массив пуст или величина сдвига кратна длине массива, массив не изменяется.

## Сложность алгоритма

- **Временная сложность:** O(n).
- **Дополнительная пространственная сложность:** O(1).

## Результаты ручного тестирования

| Входные данные | Ожидаемый результат |
|---|---|
| `5 1 2 3 4 5 2` | `4 5 1 2 3` |
| `0 3` | пустая строка |
| `3 1 2 3 4` | `3 1 2` |
