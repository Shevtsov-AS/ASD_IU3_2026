# Задача № 37. Разворот массива на месте

## Формат входных данных

В первой строке вводится целое число `n` — количество элементов массива. Во второй строке вводятся `n` целых чисел, разделённых пробелами.

## Формат выходных данных

Программа выводит элементы массива в обратном порядке, разделяя их пробелами.

## Алгоритм решения

Используем два индекса: один указывает на начало массива, другой — на конец. Меняем местами соответствующие элементы, после чего сдвигаем оба индекса к середине. Процесс продолжается, пока индексы не встретятся или не пересекутся.

Массив изменяется на месте, поэтому дополнительный массив не создаётся. Для пустого массива и массива из одного элемента изменений не требуется.

## Сложность алгоритма

- **Временная сложность:** O(n), где n — количество элементов массива.
- **Дополнительная пространственная сложность:** O(1).

## Результаты ручного тестирования

| Входные данные | Ожидаемый результат |
|---|---|
| `5 1 2 3 4 5` | `5 4 3 2 1` |
| `0` | пустая строка |
| `2 7 -2` | `-2 7` |
