# Задача 41. Удаление элемента

## Условие

Дан массив целых чисел и число `x`. Необходимо удалить все вхождения `x` из массива и вывести полученный массив.

## Формат ввода

- Первая строка: целое число `n` — количество элементов массива.
- Вторая строка: `n` целых чисел — элементы массива.
- Последняя строка: целое число `x` — элемент, все вхождения которого нужно удалить.

## Формат вывода

Элементы результирующего массива через пробел. Если все элементы удалены, выводится пустая строка.

## Алгоритм

1. Первый проход по массиву подсчитывает количество элементов, не равных `x`.
2. Создаётся новый массив необходимой длины.
3. Второй проход копирует в новый массив только элементы, не равные `x`.
4. Результирующий массив выводится через пробел.

## Сложность

Временная сложность: O(n), так как массив обходится два раза.

Дополнительная пространственная сложность: O(n), так как создаётся новый массив для результата.

## Ручные тесты

| Входные данные | Ожидаемый результат |
|---|---|
| `6 1 2 3 2 4 2 2` | `1 3 4` |
| `3 5 5 5 5` | Пустая строка |
| `3 1 3 4 2` | `1 3 4` |
