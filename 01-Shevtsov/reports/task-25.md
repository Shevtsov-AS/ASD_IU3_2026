# Задача № 25. Сумма элементов массива

## Алгоритм решения

Последовательно просматриваем все элементы массива и накапливаем их сумму. Для хранения результата используется тип `long`, чтобы уменьшить риск переполнения по сравнению с типом `int`.

Если массив пуст, цикл не выполняется и результат остаётся равным нулю.

## Сложность алгоритма

- **Временная сложность:** O(n), где n — количество элементов массива. Каждый элемент обрабатывается один раз.
- **Дополнительная пространственная сложность:** O(1) для вычисления суммы, не считая памяти, занятой входным массивом.

## Результаты ручного тестирования

| Входные данные | Ожидаемый результат |
|---|---:|
| `3 1 2 3` | `6` |
| `4 -1 2 -3 4` | `2` |
| `0` | `0` |
